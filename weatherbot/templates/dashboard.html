Error is the model's out-of-sample MAE/RMSE (physical units, averaged across all points and variables) on each day, measured before that day is used to update the model — this is the walk-forward part: score on the next unseen day, then learn from it, then move forward. Training has no fixed end date; once it reaches the most recent day in the store it waits and resumes automatically if more data appears. Chart is downsampled for display when the history is long.

Each path starts from the model's current state at this point and is simulated forward day by day, adding random noise scaled to the model's own tracked forecast-error variance at each step — so paths diverge more over a longer horizon, the same way real forecast uncertainty compounds. Bands are ensemble percentiles at each forecast day, not a single deterministic prediction.
