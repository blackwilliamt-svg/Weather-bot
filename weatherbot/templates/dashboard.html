Each path starts from the model's current state at this point and is simulated forward day by day, adding random noise scaled to the model's own tracked forecast-error variance at each step — so paths diverge more over a longer horizon, the same way real forecast uncertainty compounds. Bands are ensemble percentiles at each forecast day, not a single deterministic prediction.
